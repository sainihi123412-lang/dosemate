# Dosemate Wellness Tracker

A men's daily wellness & hair growth companion powered by Man Matters.

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** (bundler)
- **Tailwind CSS** (styling)
- **lucide-react** (icons)

## Run Locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

Follow the prompts — Vercel auto-detects Vite. Your app will be live at a `.vercel.app` URL in ~60 seconds.

## Features

- 📋 Multi-product daily dose tracker with streak tracking
- 💊 Smart meal-timed reminders
- 📸 Before & after hairline progress photo comparison slider
- 🤖 AI specialist chatbot (Ask Queries)
- 🛒 Man Matters product catalog
- 👤 Health profile & onboarding wizard
- 💾 Full local-storage persistence (no backend needed)
